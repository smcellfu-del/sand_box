EVIDENCE GATE
------------------------------------------------------------------------------------------------
A substitution receives a positive score only when:
    raw_count >= MIN_PAIR_COUNT
and song_count >= MIN_SONG_COUNT

Otherwise the substitution score remains exactly 0.0,
the same as an ordinary unseen mismatch.

SCORING FORMULA
------------------------------------------------------------------------------------------------
1. Exact match:
   S(l,l) = MATCH_SCORE

2. Reviewed substitution that FAILS the evidence gate:
   S(l,w) = UNSEEN_MISMATCH_SCORE = 0.0

3. Reviewed substitution that PASSES the evidence gate:
   effective_count = count - MIN_PAIR_COUNT + 1

   S(l,w) = MAX_SUB_SIMILARITY
            * effective_count
            / (effective_count + SATURATION_K)

4. Unseen mismatch:
   S(l,w) = 0.0

IMPORTANT
------------------------------------------------------------------------------------------------
P(ASR|Lyrics) is printed only as descriptive statistics.
It does NOT directly determine the similarity score.

The similarity score is evidence-driven:
repeated substitutions across multiple songs receive bonus;
single / isolated observations remain ordinary mismatches.
