WHAT THIS REPORT CALCULATES
------------------------------------------------------------------------------------------------
This report uses only human-reviewed substitution errors
(review.use_for_matrix == True).

For each Lyrics phoneme, it first counts all reviewed
substitution errors produced from that source phoneme.

Then each pair is converted to:

    pair_count / all_substitution_errors_from_that_Lyrics_phoneme

Example:
    d -> t = 6
    d -> b = 1
    total errors from d = 7

    d -> t = 6 / 7 = 0.8571
    d -> b = 1 / 7 = 0.1429

IMPORTANT
------------------------------------------------------------------------------------------------
These values describe the current reviewed confusion distribution.
They are NOT yet the final Needleman-Wunsch substitution scores.
Sample-size confidence / smoothing / score mapping can be added later.
